# 幻想智多星｜首頁登入背景圖 美工設計規範

以第一張 `bg.webp` 為基準。所有登入背景圖都照這份規範製作，換圖時登入卡片位置才會完全一致、不會忽高忽低。

---

## 1. 檔案規格

| 項目 | 規格 |
|---|---|
| 尺寸 | **1024 × 1536 px**（直式 2:3）。可用 1080 × 1620，比例相同即可 |
| 格式 | WebP，品質約 80，sRGB 色彩 |
| 大小 | 每張 **300 KB 以內**（手機載入速度） |
| 檔名 | 英文小寫，例如 `bg3.webp`、`xmas.webp`、`newyear.webp` |
| 交付 | 另附一張未壓縮的 PNG 原檔＋分層檔（PSD），方便日後修改 |

## 2. 版面分區（以 1024 × 1536 為準）

```
 0 ┌──────────────────────────────┐
   │ ① 頂端留白（只放星空）        │  右上角 80×80 不放東西（聲音按鈕）
 60├──────────────────────────────┤
   │ ② 標題區                      │  幻想智多星 / FANTASY STAR / 開啟你的智慧冒險
300├──────────────────────────────┤
   │ ③ 角色區                      │  4 位角色 + 2 隻寵物，全身入鏡
   │                              │  腳底、寵物底部不可超過 940
 952├──────────────────────────────┤ ← 登入卡片從這裡開始蓋住（固定 62%）
   │ ④ 卡片區（只放星空，無人物、無文字）│
1300│   ↓ 漸層                     │
   │ ⑤ 底部漸層成單一底色 #322888    │
1536└──────────────────────────────┘
```

| 區域 | 高度範圍 (px) | 內容 | 規則 |
|---|---|---|---|
| ① 頂端留白 | 0 – 60 | 星空 | 手機狀態列可能蓋住；**右上角 x 944–1024、y 0–80 不放任何元素**（聲音按鈕位置） |
| ② 標題區 | 60 – 300 | 標題組 | 標題組寬度 ≤ 760 px、水平置中；**每張圖位置相同（誤差 ±10 px）** |
| ③ 角色區 | 300 – 940 | 角色、寵物、場景 | 角色全身入鏡；**最低點（腳底、寵物）≤ 940** |
| ④ 卡片區 | 952 – 1300 | 星空、淡淡雲霧 | **不放人物、文字、重要物件**（會被登入卡片蓋住） |
| ⑤ 底部漸層 | 1300 – 1536 | 漸層到底色 | 最下方 50 px 為單一色 **#322888** |

**左右安全邊**：x 0–60 與 x 964–1024 只放背景（不同手機會裁切）。

## 3. 標題組（每張圖都一樣）

- 主標：**幻想智多星**（字一定要正確，不是「智慧星」）
- 英文：**FANTASY STAR**（兩側細線裝飾）
- 副標：**開啟你的智慧冒險**（兩側金色小星）
- 金色描邊、紫色漸層字面、上方一顆四芒星。
- **建議做成一個固定的標題圖層**，每張圖直接沿用，位置、大小不變；只換背景和角色。
- AI 繪圖常把中文字畫錯，**標題請用設計軟體另外疊上去**，不要讓 AI 生成文字。

## 4. 風格與色彩

| 項目 | 規範 |
|---|---|
| 畫風 | Q 版（約 2.5 頭身）日系動漫、精緻厚塗、柔光 |
| 主色 | 星雲紫、夜空藍 |
| 重點色 | 金色（標題、星光、飾品） |
| 輔助色 | 銀白（星點、光暈） |
| 氛圍 | 夢幻星空、魔幻、溫暖友善（使用者是國小學生） |
| 場景元素 | 漂浮城堡、星空、光環魔法陣、星光粒子；可依主題加特色（櫻花、雪、燈籠…） |
| 角色 | 4 位（男女各 2）＋ 2 隻寵物；造型可換，**數量與大小比例固定** |
| 禁止 | 登入框、按鈕、文字說明、浮水印、恐怖或暴露元素 |

## 5. 交付前自我檢查

- [ ] 1024 × 1536，WebP，300 KB 以內
- [ ] 標題是「幻想智多星」，位置與第一張相同
- [ ] 角色與寵物最低點在 940 以上
- [ ] 952 以下只有星空，最下方是 #322888
- [ ] 右上角與左右 60 px 沒有重要元素
- [ ] 沒有登入框、按鈕或多餘文字
