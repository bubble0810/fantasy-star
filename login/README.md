# login／首頁登入畫面專用素材

這個資料夾只放登入畫面用的圖，和 `outfits/` 換裝圖分開。

## 目前檔案
| 檔案 | 用途 |
|---|---|
| bg.webp | 預設背景圖（1024×1536） |
| login-art.js | 換圖設定：什麼時間用哪張圖 |

## 換圖規則（login-art.js）
由上往下比對，第一個符合、而且讀得到的圖就用：
1. 節慶期間（跟遊戲內節慶活動日期同步）
2. 自訂日期（每年固定月-日，可跨年）
3. 白天／夜晚
4. 預設圖 bg.webp

圖還沒放進來也沒關係，讀不到會自動換下一張。改完 login-art.js 後，把 index.html 裡 `login-art.js?v=` 的版本號改一下。

## 圖片規格
- 1024×1536 或 1080×1620（直式 2:3），WebP，300 KB 以內
- 上方 62%：標題（幻想智多星／FANTASY STAR／副標）＋人物
- 下方：只放星空，登入卡片會蓋在這裡；最下面漸層成深紫色（目前底色 #322888）
- 左右各留 60px 安全邊；每張圖構圖、標題位置一致，換圖才不會跳動
