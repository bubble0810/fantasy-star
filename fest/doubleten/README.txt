幻想智慧星｜國慶旗海慶典（主頁整合版）
==================================================

放置位置：fest/doubleten/
  index.html   遊戲本體（直接開啟即可玩）
  music.js     原創 116 BPM 輕快典禮進行曲（合成銅管、短笛、小鼓）
  game.css     共用介面適配、可捲動說明卡及行動裝置直式提示
  README.txt   本說明
  img/         背景 bg.jpg + 由元件總圖切圖去背的 PNG

玩法摘要
- 60 秒單關；按住角色（手機手指／電腦滑鼠左鍵）在矩形廣場 360° 拖曳
- 彩虹旗生命週期 3.6 秒：0–0.18 淡入、0.18–3.25 光圈亮起可收集、3.25–3.6 淡出
- 場上最多 8 面旗；前、中、後段每 0.45／0.36／0.30 秒出旗（間隔隨機浮動 ±20%）
- 旗海：1–11 面 1 條、12–23 面 2 條、24 面以上 3 條（跟隨節點慣性，掉旗自動降級）
- 功能旗第 8 秒首次出現，之後每 4–6 秒獨立隨機抽一種，不限制每局種類或總次數；每面停留 5 秒
- 加速／無敵／倍率×2 取得後各維持 5 秒，三種可同時生效；同種再次取得刷新為 5 秒，不累加倍率
- 角色高度 130；旗海尾巴旗子尺寸 56、節點間距 30（邏輯像素）
- 煙火：紅圈預警 1 秒 → 爆發 1 秒，整段爆發期間進入範圍都可能受傷；每顆煙火最多命中一次
- 被擊中向爆炸中心外退最多 85 邏輯像素、跌坐 0.55 秒，受擊保護 1 秒；沒有無敵時損失目前旗數約 20%（最少 1、最多 5）
- 成績＝60 秒結束時保留的旗數
- 點擊開始後播放配樂，可用右上共用音樂按鈕靜音；結束、離開與切到背景時停止
- 升空火箭縮為 72 邏輯像素；煙火爆炸圖、紅圈與判定半徑維持原設定

正式串接與獎勵
- national 使用 common.js/common.css，主頁與後台共用 festival-config.js；開放日期沿用主頁設定
- 正式每日 3 次，開始前由主頁確認並扣次，結算確認後才入帳；中途離開不發獎、不退次數
- 完成獎勵 20 國慶徽章＋每保留 4 面旗加 1，每場最多 60；旗數成績與活動貨幣分開顯示
- 男生／女生造型各 240 國慶徽章，共用房間 300；物品沿用 L-MSP08/L-FSP08、SP08
- 星宮體驗每次 50 星星糖、每遊戲每日 3 次，不發正式貨幣、不占正式活動次數
- 使用 fsGameReady/Start/Result/Replay/Close 協定，由共用層附上 national 與 session；不再送出舊 doubleten_result
- 圖片或配樂載入失敗時禁止開始，不扣次或收費，可從說明卡離開
- 手機／觸控平板橫放會顯示轉直提示並阻擋操作；電腦保持直式遊戲框。開局後計時不因切換背景或橫放暫停

實機微調
所有數值都集中在 index.html 最上方的 CONFIG 區塊，例如：
  FOLLOW              角色跟隨係數（0.18）
  FLAG_LIFE / FLAG_ACTIVE_END   彩虹旗存在時間與光圈結束時間
  FLAG_INTERVAL       三個時段的出旗間隔
  POWER_FIRST / POWER_INTERVAL  功能旗首次出現秒數與後續隨機間隔
  POWER_LIFE          功能旗停留秒數（5）
  FW_INTERVAL         三個時段的煙火間隔
  FW_LOSS_RATE/MIN/MAX  被煙火擊中的掉旗量
  TRAIL_SPACING / CHAIN_OFFSET / CHAIN_SPREAD  旗海間距與三條旗海的分開程度

主遊戲串接
- 主頁依玩家目前角色傳入 ?char=m 或 ?char=f，自動使用男生／女生國慶造型；仍相容舊版 boy/girl 參數
- 開場只預覽對應角色，遊戲內不提供男女切換；未傳入參數的獨立試玩預設女生
- 結束時寫入 localStorage：fs_doubleten_last（本局結果 JSON）、fs_doubleten_best（最佳旗數）
- 本機結果含 flags、earned、collected、lost、hits、blocked；正式入帳由主頁獨立確認，重玩會建立新 session

驗證
- node verify-doubleten.cjs：正式扣次、結算、重玩、離開、體驗、兌換、主頁及後台、素材失敗、直式限制、效果及煙火判定（Firebase 使用模擬資料）
- node render-doubleten-audio.cjs：配樂渲染與削波檢查，試聽輸出 artifacts/doubleten-review/doubleten-march.wav
- node balance-festivals.cjs：各節慶獎勵與全套所需天數的情境試算，非玩家實測
