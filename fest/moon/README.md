# 中秋月華祭（開發試玩版）

遊戲鍵 `moon`，網址 `fest/moon/index.html`，素材在 `img/`。可直接開啟或透過靜態伺服器試玩。主站維持 `coming-soon`，未設定正式場次、造型與小屋價格，尚未正式開放。

## 2026-11-10 玩法修訂

關卡順序為「第一關嫦娥奔月 → 第二關玉兔接月餅」。奔月完成時間影響第二關金月餅出現率：30 秒內（含）相對 +50%、超過 30 秒至 60 秒（含）+30%、超過 60 秒至 90 秒（含）+10%、超過 90 秒不加成。基礎機率為月餅中的 24%，乘算後依序為 36%、31.2%、26.4%、24%，不影響桂枝的 29% 出現率，不疊加不同級距。

奔月從按下開始並獲主頁授權後計時，到第八次飛行抵達月宮為止，包含失誤、等待光圈和飛行動畫；切換分頁與離開確認不暫停。不因超過 90 秒而失敗。中場顯示用時、相對加成與實際機率；按「開始玉兔接月餅」才開始第二關的獨立 30 秒倒數。新局重設加成，不沿用上一局。

第二關為 30 秒、左中右三軌。三隻玉兔分別位於底圖下方平台中央的左、中、右位置；中間與右邊造型互換，素材欄順序為 0、2、1，所有動作與造型一起對應。直接在兔子軌道按住上滑跳接、下滑神隱，垂直移動達 16 CSS 像素且明顯大於水平位移時立即觸發，不用放手。每個觸點只觸發一次，支援雙指同時控制不同軌道；輕點、水平拖曳及取消不觸發。軌道顯示簡短滑動提示、觸控框及暈眩提示，不再使用上下操作按鈕。電腦保留 A/S/D 跳接、Z/X/C 神隱，聚焦軌道亦可用上下箭頭。

- 普通月餅暫定 +1、金月餅 +3。接取有擴散光環、光點與數量飄字；金月餅額外讓接取的那隻兔子獲得 4 秒免暈眩，顯示金色護罩與秒數，再次接取金月餅刷新為 4 秒，不累加。護罩擋下桂枝有光波與提示，不中斷當前動作、不計入受擊次數，到期恢復普通受擊規則。
- 普通與金色月餅在下落途中持續檢查；跳躍中的手部接取區與月餅實際不透明部分相交，即刻收取並移除。未接到的月餅到達上移後的消失線就消失，消失線依跳躍最高接取點下降 7.5% 跳高設定；蹲坐、神隱、暈眩都接不到，漏接不扣除。一跳可接多顆，每顆只計一次。
- 兔子縮至 180 × 270（原 230 × 345，約縮小 22%），腳底位置為 (280,1300)、(512,1320)、(744,1300)，滑動軌道中心同步對齊。跳高 180；消失線依抬高手部（身高 64% 處）的最高點再下降 7.5% 跳高計算。三種兔子的起跳與接取姿勢各自校準手部區域，繪圖與判定共用同一姿勢、座標、尺寸及縮放；桂枝與兔子實際不透明區相交即受擊，受擊特效放在接觸點，空中受擊以 0.22 秒回落，不瞬間傳送到地面。
- 普通月餅顯示框 116、金月餅 132（原本皆為 76），金色略大且保留光效。每顆月餅的下落時間為 1.6～2.4 秒，沿單調向下曲線緩和加減速（瞬時相對基準速度約 ±22%），不會反向或在途中突然重抽速度；抵達原跳接高度即判定消失。桂枝固定 2.1 秒抵達受擊高度，保留可辨識的閃避節奏。
- 桂枝沿途與月餅一起計算接觸時刻，再繼續往下消失。無護罩時只有縮小後的神隱能避開；蹲坐或跳躍的可見部分碰到都會被擊中，暈眩 0.85 秒，只限制跳接與神隱，不扣月餅。受擊有紫色衝擊波、碎光、暈眩飄字、搖晃與頭頂旋轉星星。
- 跳躍 0.9 秒、神隱基本 1.8 秒（原 0.95 秒）。神隱以 0.12 秒快速縮小，維持縮小與透明，最後 0.18 秒才恢復；畫面與避撞共用同一縮放值，縮至 35% 以下才安全。若恢復前桂枝正在接近或穿過該兔子的身體範圍，自動延長神隱至該枝通過，再探頭；不會為尚在遠處的新桂枝持續等待。神隱中不能跳接或重新發動動作，暈眩期間不能操作；其他兔子不受影響。
- 倒數依實際經過時間計算，切換分頁、離開確認不暫停。30 秒後不再收取未抵達的物件。
- 暫定兌換為剩餘存量 ×2，每局最高 60 活動月餅；這是開發值，未經玩家試玩平衡。兩關都完成、第二關 30 秒結束才結算；第一關與中場不發獎，中途退出不發獎。

第一關只需八次成功判定，對應七座背景雲台及最終月宮。第一個光圈在開始時隨機產生，之後每次成功、嫦娥開始漂浮飛升時才抽取下一個光圈的速度、金色目標位置與寬度；漂浮期間不顯示判定圈，抵達後才顯示已準備好的下一組。不預先固定八組順序。速度分成快、中、慢三類，相鄰兩次不重複同一類，各類內再隨機微調，完整週期約 1.05～2.0 秒；目標位置與寬度隨機抽取，成功時窗收窄為 0.26～0.40 秒。判定圈與底盤同步縮小約 20%，文字與線寬配合縮小，畫面與實際判定一致。畫面金色帶與實際判定共用同一組參數；同一次判定與失誤重試維持原速度、位置、寬度，不中途突變。失誤不退進度，等待下一圈即可重試，不要求每座點兩次。飛行中忽略重複點擊；每次飛行 2.4 秒，沿持續上升的柔和曲線漂移，不做拋物線跳起落下；四段姿勢交疊淡化、金紫流光尾跡、月華光暈、持續輕浮動與漸遠縮小表現靈動幻化。

## 素材與去背檢查

舊 `rabbit_*.png`、`change_*.png` 保留供對照，遊戲不再載入。舊嫦娥裁圖含綠底及鄰接角色碎片；舊兔子和本次提供的三兔造型不同。

- `rabbits-alpha-v2.png`：使用者第三張圖的三欄、三列九動作。每欄對應同一隻兔子，上中下列分別為蹲坐、起跳、接取；神隱以縮小、淡出、地面光環表現，暈眩以搖晃、頭頂星星表現。
- `moon-atlas-alpha-v2.png`：從使用者第二張圖選取八件素材，整理為四欄兩列。上列依序為嫦娥立雲、滑行、伸手飛升、正面漂浮；下列為持月嫦娥、普通月餅、金月餅、桂花枝。桂花為枝條圖案，不另設增益物件。
- 兩張圖皆經內建 imagegen 去背；程式檢查真實 alpha，深色底合成檢查毛邊、薄紗與綠邊。生成結果保留原始輸出，專案使用版本化檔名。
- 背景沿用 `rabbit-bg.jpg`、`moon-bg.jpg`，不去背。雲台沿用背景已有位置，不另疊浮雲。判定圈使用 canvas 繪製，確保金色範圍和判定一致。

## 配樂與音效

`music.js` 使用原創 Web Audio 合成配樂，非現成歌曲或真實樂器錄音。

- 第一關：96 BPM、八段主題，以笛聲、古箏／琴感撥弦、輕祭典鼓、鈴與小鑼營造中國古典融合日式祭典的月夜氛圍。融合修訂版延長笛聲句尾，加入較圓潤的第二種弦音，在主旋律之間互相應答，以柔和持續和聲串起兩種撥弦音色；鼓與鈴沿同一節奏輕輕穿插，減少音色分段感。橋段降低密度，輪迴有伴奏變化。
- 第二關：144 BPM、八段旋律，使用帶滑音的伽倻琴感撥弦、明亮高音、跳動低音、切分伴奏與低／高鼓對答，呈現活潑韓風節奏。這些為風格化合成設計，不宣稱還原傳統樂器或固定傳統節奏。
- 跳接為上行滑音，神隱為下行音加氣流；普通月餅為短鈴、金月餅為上行琶音，護罩擋擊為雙鈴光波；受擊為柔和低鼓、下滑音與暈眩鈴，閃躲為短撥弦回應。
- 飛升為逐步上行月華鈴，判定失誤為低調雙音，抵達與通關為弦音和弦、小鑼與鈴。
- 音樂只在開始獲准後播放；第一關完成停止配樂並播放抵達音，中場等候不循環播放；第二關開始切換配樂，結算停止配樂並播放通關音。離開確認不暫停，頁面關閉時停止所有聲源。
- 配樂與音效共用一個 AudioContext，分別透過音量匯流排後接 `FSGame.output`，共用靜音與限幅，不直接繞過至喇叭。

執行 `node render-moon-audio.cjs` 可產生 40 秒奔月、32 秒玉兔、22 秒音效試聽 WAV，檢查峰值、RMS 與各種音效是否有聲；也可單獨加參數 `moon`、`rabbit` 或 `effects`。檔案在 `artifacts/festivals/moon-*-music.wav`。程式量測不代表真人試聽，仍須在實際手機校準音色、配樂與音效比例。

## 共用流程

已接 `../common.js`、`../common.css`，`data-game-key="moon"`。素材載入完成前禁止開始；正式開始由主頁授權，結算使用 `fsReport(earned)` 回報 `fsGameResult`，由主頁核對 session 並入帳。獨立試玩不發正式貨幣，再玩與離開沿用主系統規則。音效接 `FSGame.output`，使用共用靜音與限幅。HUD 為左離開、中時間／進度、右存量，聲音在右側第二列。

## 驗證

`collision.js` 與 `collision-masks.js` 共用於實際遊戲及模擬：以來源圖 alpha ≥96 的部分建立遮罩，透明留白、弱光暈不碰撞。場景以 1 像素格點取樣，每 4 毫秒掃描移動，再以二分細化接觸時刻至 0.125 毫秒。這是離散近似，並非無誤差的連續幾何。所有事件依接觸時刻處理，受擊或取得金色護罩後，重新檢查剩餘事件；完全同一時刻優先處理金月餅，再處理桂枝，避免陣列順序決定結果。

更新來源素材後執行 `node build-moon-collision.cjs` 重新產生遮罩；原始圖雜湊會由測試核對。遮罩預先存入 JS，直接開啟本機 HTML 也能工作，不依賴本機頁面的 canvas 像素讀取權限。

執行 `node verify-moon-collision.cjs`：210 組跳躍時間掃描、366 組左右偏移掃描，逐一覆蓋三兔與普通／金色月餅；另測普通後碰枝、金色後碰枝、先碰枝再碰金色、反轉陣列順序、一跳接兩顆、蹲坐漏接、神隱延長，以及不同更新頻率。模擬報告在 `artifacts/festivals/moon-collision-report.json`，範圍疊圖在 `moon-collision-ranges.png`。網址加 `?debug=1` 可顯示素材邊界、手部接取區、物件邊界及消失線。

根目錄執行 `node verify-moon.cjs`，需要 Codex 隨附 Playwright、sharp 與 Microsoft Edge。檢查 alpha、三軌、不同狀態接取／受擊、存量下限、30 秒、八次判定、手機與桌面 HUD、嵌入 session 單次回報及再玩訊息；嵌入流程使用替代主頁，不接觸正式帳戶。

截圖位於 `artifacts/festivals/moon-*.png`。正式發布前仍需真人試玩，校準頻率、跳接手感、暈眩及兌換值，確認每日場次與商店價格，再執行整站驗證。
